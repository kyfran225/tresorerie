# Guide Utilisateur - Application de Trésorerie Associative

Bienvenue dans votre nouvel outil de gestion financière. Cette application a été conçue pour être simple, rapide et utilisable directement sur votre smartphone.

## 1. Connexion
- **Lien** : Rendez-vous sur la page d'accueil.
- **Identifiants par défaut** :
  - Admin : `admin@association.com` / `admin123`
  - Adjoint : `assistant@association.com` / `admin123`

## 2. Tableau de Bord
Le tableau de bord vous donne une vue d'ensemble en temps réel :
- Nombre total de membres.
- Total des fonds collectés.
- Nombre de cotisations en cours.
- Historique des 5 derniers paiements.

## 3. Gestion des Membres
- Pour ajouter un membre : Allez dans **Membres** > **Nouveau**.
- Remplissez le nom, le téléphone et l'email.
- Vous pouvez consulter l'historique d'un membre en cliquant sur son nom.

## 4. Cotisations
Avant d'enregistrer un paiement, vous devez créer une cotisation :
- Allez dans **Cotisations** > **Créer**.
- Types disponibles : Mensuelle, Annuelle, Exceptionnelle.
- Définissez le montant et la période.

## 5. Enregistrer un Paiement
- Cliquez sur le bouton **"+"** (Enregistrer) sur le Dashboard ou via le menu **Paiements**.
- Sélectionnez le membre et la cotisation correspondante.
- Le montant se remplit automatiquement (mais peut être modifié).
- Sélectionnez le mode de réception (Espèces, Wave, Orange Money, etc.).
- Validez.

## 6. Reçus PDF
- Une fois le paiement validé, vous pouvez générer un reçu officiel.
- Le reçu contient le numéro unique, les détails du membre, le montant et la signature électronique.

## 7. Rapports et Exports
- Allez dans la section **Rapports**.
- Consultez les statistiques globales.
- Cliquez sur **Excel** ou **CSV** pour télécharger l'intégralité des transactions pour votre comptabilité.

---
*Note : Cette application est optimisée pour mobile. Pour une meilleure expérience, ajoutez-la à l'écran d'accueil de votre smartphone.*
